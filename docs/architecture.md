# 🏗 Архитектура AgentMemory

AgentMemory — локально управляемая multi-model AI-система для совместной работы нескольких AI-моделей над программными проектами.

Система объединяет долговременную память, маршрутизацию задач, управление контекстом, независимую проверку результатов и безопасную работу с Git.

## Основные компоненты

### 🧠 Memory Layer

Хранит долговременный контекст проектов:

- текущее состояние;
- принятые решения;
- следующие задачи;
- правила работы AI;
- накопленные технические уроки.

Markdown используется как человекочитаемый источник истины.

### 🧭 Model Router

Определяет, какой AI-исполнитель подходит для конкретной задачи и роли.

Пример:

```text
IMPLEMENTER  → Codex
ARCHITECT    → Claude
CRITIC       → Claude
LOCAL_WORKER → Qwen
```

### 📦 Context Layer

Перед вызовом AI система формирует ограниченный контекст задачи.

Контекст:

- выбирается из памяти;
- ограничивается по размеру;
- проверяется на чувствительные данные;
- связывается с конкретной задачей и состоянием проекта.

### 🔐 Security Layer

Используются:

- фильтрация секретов;
- ограничения чувствительных файлов;
- контроль контекста;
- изоляция Git-изменений;
- независимые проверки;
- fail-closed поведение.

### 🌳 Git Workflow

```text
Task
  ↓
Isolated Worktree
  ↓
Implementation
  ↓
Automated Tests
  ↓
Independent Review
  ↓
Change Gate
  ↓
Human Approval
  ↓
Merge
```

## Основные принципы

- разделение ролей между AI-моделями;
- долговременная память;
- минимально необходимый контекст;
- независимая проверка результатов;
- fail-closed для критических сценариев;
- изоляция изменений;
- финальный контроль человека.
