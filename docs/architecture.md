# 🏗 Архитектура AgentMemory

AgentMemory — локально управляемая multi-model AI-система, которая координирует несколько специализированных AI-моделей при работе над программными проектами.

Основная задача системы — объединить долговременную память, маршрутизацию задач, контроль контекста, независимую проверку результатов и безопасную работу с Git-репозиториями.
