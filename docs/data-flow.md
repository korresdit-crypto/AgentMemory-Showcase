# 🔀 Data Flow

AgentMemory разделяет получение задачи, подготовку контекста, выполнение и проверку результата.

## Упрощённый поток

```text
Human / Workflow
      ↓
Task Definition
      ↓
Context Planner
      ↓
Memory + Code Context
      ↓
Security Filtering
      ↓
Model Router
      ↓
AI Executor
      ↓
Verification
      ↓
Git / Runtime State
```

## Основные этапы

### 1. Task Definition

Система получает цель и ограничения задачи.

### 2. Context Planning

Определяется, какие источники контекста действительно нужны.

### 3. Context Selection

Из памяти и кодовой базы выбираются релевантные данные.

### 4. Security Filtering

Перед передачей AI выполняются ограничения по чувствительным данным и размеру контекста.

### 5. Routing

Model Router выбирает подходящего исполнителя.

### 6. Execution

AI выполняет свою роль в рамках конкретного workflow.

### 7. Verification

Результат проходит автоматические и независимые проверки.

### 8. Persistence

Сохраняются только необходимые технические результаты, состояние workflow и audit-данные.

## Принцип

Каждый этап отделён от следующего, чтобы система могла проверять данные до их передачи дальше.
