# 🧠 Long-Term Memory

Одна из ключевых частей AgentMemory — общая долговременная память для нескольких AI-агентов и программных проектов.

## Зачем она нужна

Обычная AI-сессия ограничена текущим контекстом.

При длительной разработке модель может забывать:

- уже принятые решения;
- текущее состояние проекта;
- выполненные задачи;
- найденные ошибки;
- архитектурные ограничения;
- договорённости между предыдущими сессиями.

AgentMemory сохраняет эти сведения отдельно от конкретной AI-модели.

## Человекочитаемый источник истины

Основная память хранится в Markdown.

Для каждого проекта используются документы вроде:

```text
AGENTS.md
STATE.md
DECISIONS.md
NEXT.md
LESSONS.md
