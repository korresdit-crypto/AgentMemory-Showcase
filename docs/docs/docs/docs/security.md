# 🔐 Security & Privacy

AgentMemory проектируется с принципом fail-closed: если критическая проверка не может быть выполнена полностью и однозначно, система не должна молча продолжать работу.

## Основные меры

- фильтрация потенциальных секретов;
- блокировка чувствительных файлов и ссылок;
- ограничение передаваемого AI-контекста;
- контроль дочерних процессов;
- ограничение размеров входных и выходных данных;
- проверка состояния Git-репозитория;
- изоляция изменений через worktrees;
- независимая проверка результатов;
- подтверждение критических действий человеком.

## Secret filtering

AgentMemory проверяет контекст на признаки:

- API-ключей;
- access tokens;
- паролей;
- Bearer-токенов;
- приватных ключей;
- `.env`;
- `.git-credentials`;
- `.netrc`;
- `.npmrc`;
- других потенциально чувствительных данных.

Если элемент определяется как чувствительный, он не должен передаваться AI-исполнителю.
