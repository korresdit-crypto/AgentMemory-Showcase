# 💰 Cost Control

AgentMemory проектируется так, чтобы сильные облачные модели использовались там, где они действительно нужны.

## Основная идея

Не каждая задача требует дорогого облачного AI.

Простые и вспомогательные операции могут выполняться локально.

## Пример разделения

```text
Simple / Local Task
        ↓
      Qwen

Complex Architecture
        ↓
      Claude

Code Implementation
        ↓
      Codex

External Research
        ↓
   Research Route
```

## Что помогает контролировать стоимость

- role-based routing;
- локальная модель;
- ограничение контекста;
- bounded outputs;
- отсутствие лишних повторных вызовов;
- focused verification вместо полного повторного анализа;
- reuse уже подтверждённых результатов.

## Принцип

Самая сильная модель не должна автоматически использоваться для каждой задачи.

Цель — подобрать минимально достаточный уровень ресурса без потери качества критических этапов.
