# 🔄 Memory Sync

AgentMemory синхронизирует человекочитаемую Markdown-память с машинным индексом.

## Общая схема

```text
Markdown Files
      ↓
Parse
      ↓
Validate
      ↓
Index
      ↓
Search / Context
```

## Что проверяется

При синхронизации важно убедиться, что:

- документы имеют ожидаемую структуру;
- project identity корректна;
- индекс соответствует текущей памяти;
- удалённые или изменённые данные корректно отражены;
- ошибки парсинга не превращаются в частично успешный sync.

## Почему это важно

Если индекс отстаёт от Markdown, AI может получить устаревший контекст.

## Принцип

```text
Markdown → Index
```

а не наоборот.

Машинный индекс остаётся производным слоем и должен быть восстановим из человекочитаемой памяти.
