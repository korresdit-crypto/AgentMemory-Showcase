# 🔍 Multi-Model Verification

AgentMemory использует несколько AI-моделей не только для выполнения задач, но и для независимой проверки результатов.

## Зачем это нужно

Одна модель может:

- пропустить ошибку;
- неверно понять ограничения;
- переоценить качество собственного решения;
- не заметить противоречие в контексте.

Поэтому результат одного исполнителя может проверяться другим.

## Упрощённая схема

```text
Implementation
      ↓
Primary Result
      ↓
Independent Reviewer
      ↓
Findings / Risks
      ↓
Gate Decision
```

## Примеры ролей

- Codex — реализация;
- Claude — архитектурный review и критика;
- Qwen — локальная дополнительная проверка;
- Grok — внешний research и независимый анализ.

## Принцип

Независимая проверка не должна автоматически доверять самооценке исполнителя.

Система отдельно анализирует:

- findings;
- severity;
- evidence;
- соответствие ожидаемому commit;
- полноту проверки.

## Цель

Multi-model verification снижает зависимость от одной модели и делает AI-assisted разработку более проверяемой.
