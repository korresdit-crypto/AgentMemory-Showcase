# 📜 Memory Contract

AgentMemory использует устойчивую структуру долговременной памяти, чтобы разные AI могли понимать один проект одинаково.

## Основные документы

```text
AGENTS.md
STATE.md
DECISIONS.md
NEXT.md
LESSONS.md
```

## Назначение

### AGENTS.md
Правила и ограничения работы AI с проектом.

### STATE.md
Подтверждённое текущее состояние проекта.

### DECISIONS.md
Зафиксированные архитектурные и технические решения.

### NEXT.md
Ближайшие действия и открытые задачи.

### LESSONS.md
Повторно применимые выводы из разработки и ошибок.

## Почему структура важна

Без разделения памяти одна большая заметка быстро смешивает:

- факты;
- планы;
- решения;
- предположения;
- временные идеи.

Memory Contract помогает сохранять различие между этими типами информации.

## Принцип

AI должен опираться на подтверждённое состояние и решения, а не угадывать их из случайного контекста.
