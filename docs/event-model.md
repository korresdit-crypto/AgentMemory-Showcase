# 🧾 Event Model

AgentMemory использует события для фиксации значимых переходов workflow и восстановления состояния.

## Зачем нужен event-based подход

Сложный AI-workflow может состоять из множества этапов:

- routing;
- model execution;
- verification;
- testing;
- gate decisions;
- recovery;
- human approval.

События позволяют хранить историю переходов отдельно от текущего вычисленного состояния.

## Упрощённая схема

```text
Workflow Action
      ↓
Event
      ↓
State Reducer
      ↓
Current State
```

## Основной принцип

Текущее состояние не должно слепо доверять одному сохранённому полю.

Оно может вычисляться из последовательности событий и дополнительно проверяться на согласованность.

## Что это даёт

- audit trail;
- recovery;
- воспроизводимость;
- диагностику повреждённого состояния;
- возможность проверить, как workflow пришёл к текущему результату.
