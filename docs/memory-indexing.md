# 🗂 Memory Indexing

Человекочитаемая память AgentMemory хранится в Markdown, а машинные индексы используются для быстрого поиска и подготовки контекста.

## Основная схема

```text
Markdown Memory
      ↓
Sync / Parse
      ↓
SQLite / FTS5
      ↓
Search
      ↓
Context Planner
```

## Почему индекс производный

Markdown остаётся основным источником истины.

Индекс нужен для:

- быстрого поиска;
- фильтрации;
- подготовки context bundle;
- связи данных памяти с workflow.

Если машинный индекс повреждён, он должен быть восстановим из исходных Markdown-документов.

## Принцип

```text
Markdown = Source of Truth
Index    = Rebuildable Cache
```

Такой подход сохраняет память одновременно удобной для человека и пригодной для машинной обработки.
