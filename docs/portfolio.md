# 👤 Portfolio Summary

## AgentMemory

AgentMemory — мой проект по созданию локально управляемой multi-model AI-системы с долговременной памятью, маршрутизацией задач, независимыми проверками и контролируемой работой с Git.

## Что демонстрирует проект

- проектирование архитектуры сложной AI-системы;
- работа с Python;
- Git и изолированными worktrees;
- SQLite / FTS5;
- автоматизированное тестирование;
- интеграция нескольких AI-инструментов;
- анализ и обработка ошибок;
- security-first подход;
- fail-closed проверки;
- создание воспроизводимых workflow.
