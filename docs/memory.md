# 🧠 Long-Term Memory

AgentMemory использует общую долговременную память для нескольких AI-агентов и программных проектов.

## Зачем нужна память

При длительной работе AI может терять:

- текущее состояние проекта;
- ранее принятые решения;
- выполненные задачи;
- найденные ошибки;
- архитектурные ограничения;
- важные договорённости.

AgentMemory сохраняет эти сведения отдельно от конкретной AI-сессии.
