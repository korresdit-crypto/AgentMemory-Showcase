# 🧠 Long-Term Memory

AgentMemory использует общую долговременную память для нескольких AI-агентов и программных проектов.

## Зачем нужна память

При длительной работе AI может терять:

- текущее состояние проекта;
- ранее принятые решения;
- выполненные задачи;
- найденные ошибки;
- архитектурные ограничения;
- важные договорённости.

AgentMemory сохраняет эти сведения отдельно от конкретной AI-сессии.

## Основные документы

Для проектов используются человекочитаемые Markdown-файлы:

```text
AGENTS.md
STATE.md
DECISIONS.md
NEXT.md
LESSONS.md
```

### AGENTS.md

Стабильные правила работы AI с проектом.

### STATE.md

Текущее подтверждённое состояние проекта.

### DECISIONS.md

Принятые архитектурные и технические решения.

### NEXT.md

Ближайшие задачи и дальнейшие действия.

### LESSONS.md

Накопленные выводы, ошибки и повторно применимые уроки.

## Индексация

Поверх Markdown строятся машинные индексы для быстрого поиска и подготовки контекста.

Упрощённо:

```text
Markdown
   ↓
Index / Search
   ↓
Context Planner
   ↓
Selected Context
   ↓
AI Executor
```

## Основной принцип

Markdown остаётся человекочитаемым источником истины.

Производные индексы должны быть восстановимы из исходных документов памяти.

## Privacy

Рабочая память реальных проектов в этом Showcase не публикуется.

Здесь демонстрируется только архитектурный подход без приватных данных, credentials, API-ключей и внутреннего состояния проектов.
