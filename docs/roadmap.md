# 🗺 Roadmap

AgentMemory находится в активной разработке.

## Ближайшие направления

- дальнейшее усиление multi-model orchestration;
- улучшение Model Router;
- развитие Context Planner и Context Handoff;
- расширение recovery-механизмов;
- усиление независимого review;
- дополнительные security-проверки;
- улучшение наблюдаемости workflow;
- развитие локальных AI-сценариев;
- дальнейшее тестирование на реальных проектах.

## Showcase Roadmap

Публичная витрина будет пополняться архитектурными диаграммами, примерами workflow, обезличенными результатами тестирования и дополнительной технической документацией.
