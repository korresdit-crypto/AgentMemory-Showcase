# 🛠 Tech Stack

AgentMemory объединяет локальные и облачные инструменты в одной управляемой системе.

## Основные технологии

- Python
- SQLite / FTS5
- Git
- WSL / Linux
- Docker
- Markdown / Obsidian
- MCP
- pytest

## AI-инструменты

- Codex CLI
- Claude Code CLI
- Local Qwen
- Grok API

## Для чего используется стек

Python — основной язык AgentMemory и orchestration-логики.

SQLite / FTS5 — машинный индекс для поиска по памяти.

Markdown / Obsidian — человекочитаемый слой долговременной памяти.

Git — контроль версий, изоляция изменений и проверка результатов.

WSL / Linux и Docker — локальная среда выполнения.

MCP — подключение инструментов и контекстных источников.

pytest — автоматизированное тестирование.
