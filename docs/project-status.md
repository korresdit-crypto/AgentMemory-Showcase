# 📌 Project Status

**Status: Active development**

AgentMemory используется как рабочая экспериментальная система для координации нескольких AI-моделей при разработке программных проектов.

## Реализованные направления

- долговременная Markdown-память;
- машинная индексация памяти;
- Model Router;
- Codex CLI integration;
- Claude Code CLI integration;
- локальный Qwen;
- multi-model workflows;
- Context Handoff;
- security filtering;
- Git worktree isolation;
- Git Change Gate;
- recovery и observability;
- автоматизированное тестирование.

## Testing

Проект имеет более **1100 автоматизированных тестов**.
