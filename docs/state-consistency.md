# 🧩 State Consistency

AgentMemory должен обнаруживать ситуации, когда сохранённое состояние противоречит подтверждённой истории workflow.

## Проблема

При сбое или частичной записи могут возникнуть расхождения между:

- событиями;
- runtime state;
- artifacts;
- Git-состоянием;
- текущим этапом workflow.

## Упрощённая проверка

```text
Events
  ↓
Rebuild Expected State
  ↓
Compare
  ↓
Consistent?
  ├─ Yes → Continue
  └─ No  → Block / Recover
```

## Что может проверяться

- порядок переходов;
- ссылки на artifacts;
- соответствие expected commit;
- наличие обязательных событий;
- согласованность stage и run status.

## Fail-Closed

Если состояние нельзя однозначно подтвердить, AgentMemory должен блокировать дальнейшее критическое действие.

## Цель

Не позволять повреждённому или частично записанному состоянию незаметно превращаться в успешный workflow.
