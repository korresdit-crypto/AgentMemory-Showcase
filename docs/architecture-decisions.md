# 🧠 Architecture Decisions

Этот документ показывает несколько ключевых архитектурных решений AgentMemory на высоком уровне.

## Markdown как источник истины

Человекочитаемая память должна оставаться доступной без специальной базы или AI.

Поэтому Markdown используется как основной слой проектной памяти.

## Машинный индекс как производный слой

SQLite / FTS5 и другие индексы ускоряют поиск, но не заменяют исходную память.

Индекс должен быть восстановим.

## Разделение AI-ролей

Реализация, архитектурный анализ и критика разделяются между ролями.

Это снижает зависимость от одной модели.

## Локальная модель для дешёвых задач

Qwen используется локально для задач, где не требуется дорогой облачный вызов.

## Изоляция Git-изменений

Работа AI может выполняться в отдельной ветке и worktree.

Основная рабочая копия остаётся изолированной до завершения проверок.

## Human-controlled critical actions

Успешный AI-review сам по себе не обязан автоматически выполнять merge.

Для критических действий может требоваться человек.

## Fail-Closed вместо оптимистичного продолжения

Неполная проверка, неизвестное состояние или недостаточные evidence не должны превращаться в PASS.
