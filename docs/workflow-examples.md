# 🔄 Workflow Examples

## Feature Implementation

```text
Task
  ↓
Context Planning
  ↓
Architecture / Constraints
  ↓
Implementation
  ↓
Focused Tests
  ↓
Independent Review
  ↓
Git Change Gate
  ↓
Human Approval
```

## Bug Fix

```text
Bug Report
   ↓
Reproduce
   ↓
Root Cause Analysis
   ↓
Regression Test
   ↓
Fix
   ↓
Focused Verification
   ↓
Full Test Suite
```

## Security Remediation

```text
Security Finding
      ↓
Evidence Collection
      ↓
Root Cause Analysis
      ↓
Remediation
      ↓
Security Tests
      ↓
Independent Verification
      ↓
Change Gate
```

## Research + Implementation

```text
Research Question
      ↓
External Research
      ↓
Architecture Review
      ↓
Implementation Plan
      ↓
Codex Implementation
      ↓
Verification
```

## Recovery after interruption

```text
Interrupted Workflow
      ↓
Read persisted state
      ↓
Validate repository state
      ↓
Determine safe resume point
      ↓
Resume or block for human review
```
