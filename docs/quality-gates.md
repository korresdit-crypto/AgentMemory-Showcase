# ✅ Quality Gates

AgentMemory использует набор gate-механизмов, которые отделяют выполнение задачи от признания результата готовым.

## Что может проверяться

- результаты обязательных тестов;
- состояние Git;
- корректность diff;
- наличие потенциальных секретов;
- соответствие ожидаемому commit;
- независимый review;
- отсутствие блокирующих замечаний;
- полнота evidence;
- непротиворечивость состояния workflow.

## Общая схема

```text
Implementation
      ↓
Focused Tests
      ↓
Repository Checks
      ↓
Independent Review
      ↓
Quality Gate
      ↓
PASS / BLOCKED
```

## Fail-Closed

Если проверка не может быть завершена корректно, результат не должен автоматически считаться успешным.

```text
UNKNOWN ≠ PASS
INCOMPLETE ≠ PASS
TRUNCATED ≠ PASS
```

## Цель

Quality Gates уменьшают вероятность того, что частично проверенное изменение будет ошибочно принято как готовое.
