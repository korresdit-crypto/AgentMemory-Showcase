# 🔁 Idempotency

AgentMemory стремится делать повторный запуск операций предсказуемым.

## Проблема

В распределённом или многоэтапном workflow одна и та же команда может быть вызвана повторно после:

- timeout;
- сбоя;
- перезапуска;
- неопределённого ответа;
- ручного повторения.

Без idempotency это может привести к дублирующим действиям.

## Общая идея

```text
Request
  ↓
Stable Identity
  ↓
Existing Result?
  ├─ Yes → Reuse / Validate
  └─ No  → Execute
```

## Где это полезно

- workflow runs;
- persisted events;
- gate results;
- approvals;
- artifact creation;
- recovery operations.

## Принцип

Повторный вызов с тем же смыслом не должен незаметно создавать вторую независимую историю, если система уже имеет подтверждённый результат.

## Цель

Сделать recovery и повторные операции безопаснее и понятнее.
