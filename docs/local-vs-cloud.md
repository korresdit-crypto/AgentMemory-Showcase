# ☁️ Local vs Cloud AI

AgentMemory разделяет локальные и облачные AI-маршруты.

## Local AI

Локальная модель используется там, где важны:

- низкая стоимость;
- приватность;
- быстрые вспомогательные проверки;
- классификация;
- предварительный анализ.

Основной пример — локальный Qwen.

## Cloud AI

Облачные модели используются для задач, где нужна более сильная модель или специализированная роль.

Примеры:

- Codex;
- Claude;
- Grok.

## Упрощённый выбор

```text
Task
  ↓
Role + Requirements
  ↓
Privacy / Capability / Availability
  ↓
Local or Cloud Route
```

## Принцип

Локальная модель не должна автоматически заменяться облачной, если задача требует приватного локального выполнения.

А облачный исполнитель не должен считаться доступным без проверки его readiness.

## Цель

Сочетать:

- стоимость;
- приватность;
- качество;
- доступность;
- специализацию моделей.
