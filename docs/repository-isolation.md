# 🌿 Repository Isolation

AgentMemory использует Git-изоляцию для снижения риска случайного изменения основной рабочей копии проекта.

## Основная идея

Изменения AI могут выполняться в отдельной ветке и worktree.

```text
Primary Checkout
      │
      ├── остаётся отдельно
      │
      └── Task Worktree
              ↓
          AI Changes
              ↓
            Tests
              ↓
            Review
              ↓
          Change Gate
```

## Что это даёт

- изоляцию незавершённых изменений;
- отдельный commit history для задачи;
- возможность проверить diff до merge;
- более безопасный recovery;
- защиту основной рабочей копии от случайных правок.

## Перед merge

Система может дополнительно проверить:

- состояние primary checkout;
- ожидаемый commit;
- diff;
- тесты;
- отсутствие неожиданных файлов;
- результаты независимого review.

## Принцип

Изменение кода и принятие этого изменения в основную ветку — разные операции.
