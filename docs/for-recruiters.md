# 👔 For Recruiters

AgentMemory — мой практический проект по созданию локально управляемой multi-model AI-системы для длительной работы над программными проектами.

## Что демонстрирует проект

- проектирование сложной AI-архитектуры;
- Python;
- Git и изолированные worktrees;
- SQLite / FTS5;
- автоматизированное тестирование;
- интеграцию нескольких AI-инструментов;
- security-first подход;
- recovery и audit;
- fail-closed проверки;
- управление workflow и состоянием.

## Практический результат

AgentMemory используется как рабочая экспериментальная система при разработке реальных программных проектов.

На текущем этапе проект имеет более **1100 автоматизированных тестов**.

## Что важно

Публичный Showcase не содержит основной private codebase, credentials, API-ключи, рабочую память проектов и production-конфигурацию.

Цель этого репозитория — показать архитектурный подход, инженерную дисциплину и уровень практической работы.
