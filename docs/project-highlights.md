# ⭐ Project Highlights

## Multi-model orchestration

AgentMemory распределяет роли между несколькими AI вместо использования одной модели для всех задач.

## Long-term memory

Проектная память сохраняет состояние, решения, следующие шаги и технические уроки между AI-сессиями.

## Model Router

Задачи маршрутизируются по роли, capability, readiness и ограничениям workflow.

## Context Handoff

AI получает ограниченный и проверенный контекст вместо всей памяти проекта.

## Git isolation

Изменения могут выполняться в отдельных worktrees до завершения тестов и review.

## Independent verification

Результат одного AI может проверяться другим исполнителем.

## Git Change Gate

Перед merge или push изменения могут проходить отдельный набор проверок и human approval.

## Recovery

Система сохраняет состояние workflow и может определять безопасную точку продолжения после сбоя.

## Testing

Проект имеет более **1100 автоматизированных тестов**, включая regression, security и boundary scenarios.
