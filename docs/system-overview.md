# 🧠 System Overview

AgentMemory — локально управляемая multi-model AI-система для длительной работы над программными проектами.

## Ключевые слои

```text
Human
  ↓
Long-Term Memory
  ↓
Context Planning
  ↓
Model Routing
  ↓
AI Execution
  ↓
Verification
  ↓
Security / Quality Gates
  ↓
Git / Project State
```

## Основные возможности

- долговременная память проектов;
- маршрутизация задач между несколькими AI;
- локальные и облачные модели;
- ограниченный Context Handoff;
- автоматизированное тестирование;
- независимый review;
- recovery;
- audit trail;
- Git Change Gate;
- human approval.

## Главная идея

AgentMemory не пытается сделать одну AI-модель универсальной.

Вместо этого система строит управляемую команду специализированных AI с общей памятью, проверками и контролем человека.
