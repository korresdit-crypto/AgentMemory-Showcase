# 🧪 Testing

AgentMemory развивается с упором на автоматизированное тестирование, воспроизводимость и проверку критических сценариев.

## Что тестируется

- маршрутизация задач между AI-моделями;
- работа Model Router;
- передача и ограничение контекста;
- фильтрация секретов и чувствительных данных;
- Git worktrees и изоляция изменений;
- Git Change Gate;
- обработка ошибок и восстановление;
- проверка результатов AI-моделей;
- CLI и workflow;
- fail-closed сценарии;
- security-механизмы.

## Текущее состояние

Тестовый набор проекта превышает **1100 автоматизированных тестов**.

Отдельные security-изменения дополнительно проходят специализированные тестовые наборы и независимые проверки.

Используются:

- `pytest`;
- интеграционные тесты;
- regression-тесты;
- boundary-тесты;
- security-тесты;
- проверки Git-состояния;
- `git diff --check`;
- воспроизведение реальных проблем перед исправлением.

## Принцип

Для критичных изменений применяется подход:

```text
Reproduce
   ↓
Identify root cause
   ↓
Add regression test
   ↓
Implement fix
   ↓
Run focused tests
   ↓
Run full test suite
   ↓
Independent review
```

Цель — не просто получить работающий результат, а оставить автоматическую проверку, которая не позволит той же ошибке незаметно вернуться.
