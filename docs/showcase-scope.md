# 🪟 Showcase Scope

Этот репозиторий — публичная техническая витрина AgentMemory.

## Что публикуется

- архитектура высокого уровня;
- описание подсистем;
- workflow;
- подход к тестированию;
- security-принципы;
- примеры маршрутизации;
- инженерные практики;
- обезличенные схемы.

## Что не публикуется

- основной private source repository;
- production API keys;
- токены;
- `.env`;
- приватные prompts;
- рабочая память реальных проектов;
- production runtime databases;
- внутренние конфигурации;
- чувствительные findings;
- приватные artifacts.

## Почему

Цель Showcase — доказать архитектурный и инженерный уровень проекта, не раскрывая данные, которые не нужны для портфолио.

## Принцип

Публичность должна демонстрировать работу системы, а не снижать её security boundary.
