# 🔌 MCP Integration

AgentMemory использует MCP как один из способов подключения инструментов и источников контекста к AI-исполнителям.

## Зачем нужен MCP

MCP позволяет отделить AI-модель от конкретной реализации инструмента.

Упрощённо:

```text
AI Executor
    ↓
MCP Client
    ↓
Tool / Context Provider
```

## Что это даёт

- единый способ подключать инструменты;
- более чистое разделение ответственности;
- возможность использовать разные источники контекста;
- контролируемую передачу данных;
- упрощение интеграции локальных сервисов.

## Контроль

MCP-интеграции не должны автоматически получать неограниченный доступ к проекту.

Передача контекста и вызовы инструментов остаются частью orchestration- и security-политики AgentMemory.
