# ❤️ Model Health & Readiness

AgentMemory не считает AI-исполнителя доступным только потому, что он указан в конфигурации.

## Что проверяется

Перед использованием исполнителя система может учитывать:

- наличие CLI или runtime;
- корректность локальной конфигурации;
- возможность запуска;
- доступность provider;
- готовность adapter;
- ограничения конкретного workflow.

## Упрощённая схема

```text
Configured
    ↓
Health Check
    ↓
AVAILABLE / UNAVAILABLE / UNKNOWN
    ↓
Routing Decision
```

## Принцип

```text
Configured ≠ Available
UNKNOWN ≠ Ready
```

Если исполнитель не подтверждён как пригодный для конкретной задачи, AgentMemory не должен молча маршрутизировать на него критическое выполнение.

## Зачем это нужно

Такой подход помогает избежать ситуаций, когда:

- CLI установлен, но не авторизован;
- provider временно недоступен;
- локальная модель не запущена;
- adapter не поддерживает нужную роль;
- окружение не соответствует требованиям workflow.
