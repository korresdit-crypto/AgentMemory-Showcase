# 📦 Context Handoff

Context Handoff — механизм подготовки и безопасной передачи контекста между AgentMemory и AI-исполнителями.

## Зачем он нужен

AI не должен автоматически получать всю память проекта.

AgentMemory формирует только тот контекст, который нужен для конкретной задачи.

## Упрощённый процесс

```text
Project Memory
      ↓
Context Planning
      ↓
Relevant Data Selection
      ↓
Security Filtering
      ↓
Size Limits
      ↓
AI Executor
```

## Что учитывается

При подготовке контекста система проверяет:

- источник данных;
- актуальность;
- чувствительность;
- связь с текущей задачей;
- ограничения по размеру;
- допустимость передачи конкретному исполнителю.

## Security Filtering

Перед передачей блокируются или исключаются потенциально чувствительные элементы:

- API-ключи;
- токены;
- пароли;
- приватные ключи;
- `.env`;
- credential-файлы;
- другие секреты.

## Ограничение размера

Контекст имеет ограниченный бюджет.

Если данных слишком много, система не должна бесконтрольно отправлять весь проект модели.

## Provenance

Context Handoff связывается с:

- конкретной задачей;
- workflow;
- исполнителем;
- состоянием репозитория;
- выбранными источниками памяти.

Это позволяет понимать, на основании какого контекста AI получил задачу.

## Цель

Context Handoff уменьшает риск:

- передачи лишних данных;
- утечки секретов;
- переполнения контекста;
- использования нерелевантной памяти;
- смешивания информации разных проектов.
