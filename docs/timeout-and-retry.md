# ⏱ Timeout & Retry

AI-вызовы, CLI-процессы и внешние инструменты могут зависнуть или отвечать слишком долго.

AgentMemory использует timeout policy, чтобы такие ситуации не превращались в бесконечное выполнение.

## Возможный сценарий

```text
Executor Call
     ↓
Timeout
     ↓
Classify Failure
     ↓
Retry Allowed?
     ├─ Yes → Controlled Retry
     └─ No  → Block / Fallback
```

## Что важно при retry

Повторная попытка не должна:

- бесконтрольно дублировать изменения;
- создавать несколько конфликтующих результатов;
- терять provenance;
- маскировать настоящую причину сбоя.

## Ограничения

Количество попыток и время выполнения должны оставаться bounded.

## Принцип

Retry — это контролируемый механизм восстановления, а не бесконечный цикл «попробовать ещё раз».
