# 🤖 Model Roles

AgentMemory разделяет обязанности между AI-моделями вместо использования одной модели для всех задач.

## IMPLEMENTER

Основной исполнитель изменений в коде.

Типичный исполнитель: **Codex**

Задачи:

- реализация;
- исправление ошибок;
- работа с репозиторием;
- подготовка проверяемого результата.

## ARCHITECT

Анализирует архитектуру и ограничения до или после реализации.

Типичный исполнитель: **Claude**

Задачи:

- архитектурный анализ;
- поиск противоречий;
- оценка рисков;
- рекомендации по структуре решения.

## CRITIC

Выполняет независимую проверку решения.

Типичный исполнитель: **Claude**

Задачи:

- критика реализации;
- поиск слабых мест;
- проверка assumptions;
- выявление блокирующих замечаний.

## LOCAL_WORKER

Локальная AI-модель для задач, где не нужен дорогой облачный вызов.

Типичный исполнитель: **Qwen**

Задачи:

- классификация;
- предварительный анализ;
- локальные проверки;
- дешёвый независимый second opinion.

## RESEARCHER

Исполнитель для внешнего исследования и актуальной информации.

Может использовать отдельный research-маршрут.

## Принцип

Роль и модель — не одно и то же.

AgentMemory маршрутизирует задачу по роли, доступности исполнителя и ограничениям workflow.
