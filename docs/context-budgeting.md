# 📏 Context Budgeting

Контекст AI ограничен, поэтому AgentMemory не передаёт модели неограниченный объём памяти и кода.

## Задача

Нужно передать достаточно информации для выполнения задачи, но не отправлять весь проект целиком.

## Общий процесс

```text
Available Context
      ↓
Relevance Selection
      ↓
Security Filtering
      ↓
Budget Enforcement
      ↓
Rendered Context
      ↓
AI Executor
```

## Что ограничивается

- общий размер context bundle;
- размер отдельных элементов;
- количество элементов;
- размер model-facing evidence;
- размер metadata;
- размер outputs.

## Почему это важно

Context budgeting помогает:

- уменьшать стоимость облачных вызовов;
- не перегружать модель;
- снижать риск передачи лишних данных;
- делать результаты более воспроизводимыми;
- обнаруживать неполную проверку.

## Fail-Closed

Для критичных сценариев незаметное усечение evidence не должно считаться полноценной проверкой.

Если важная проверка требует данных, которые не помещаются в допустимый budget, система должна явно зафиксировать ограничение или заблокировать действие.
