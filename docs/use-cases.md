# 🎯 Use Cases

AgentMemory создаётся для длительной работы нескольких AI над реальными программными проектами.

## Разработка
AI получает задачу и нужный контекст, выполняет реализацию в изолированной Git-среде, после чего результат проходит тесты и дополнительные проверки.

## Архитектурный анализ
Сложная задача может быть передана отдельному AI-архитектору до начала реализации.

## Независимое review
Результат одного AI может проверяться другим исполнителем.

## Security remediation
Отдельный workflow может включать анализ finding, сбор evidence, поиск root cause, исправление, regression-тесты и независимую проверку.

## Долговременные проекты
Система сохраняет текущее состояние, решения, следующие шаги, технические уроки и ограничения проекта.
