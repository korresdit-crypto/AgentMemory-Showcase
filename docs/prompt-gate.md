# 🧾 Prompt Gate

Prompt Gate — механизм проверки инструкций перед передачей их AI-исполнителю в критичных workflow.

## Зачем он нужен

Плохой prompt может содержать:

- противоречивые требования;
- недостающие ограничения;
- небезопасные инструкции;
- неясные acceptance criteria;
- неверный контекст.

## Упрощённый процесс

```text
Draft Prompt
    ↓
Validation
    ↓
Independent Review
    ↓
Locked Prompt
    ↓
AI Executor
```

## Что проверяется

- структура;
- обязательные ограничения;
- непротиворечивость;
- соответствие задаче;
- безопасность;
- полнота acceptance criteria.

## Locked Prompt

После успешной проверки утверждённая версия prompt может быть зафиксирована так, чтобы исполнитель получил именно проверенный вариант.

## Принцип

Критическая инструкция не должна незаметно изменяться между review и фактическим выполнением.
