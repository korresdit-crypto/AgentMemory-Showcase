# 🔒 Privacy Boundaries

AgentMemory разделяет приватные данные проекта и данные, которые допустимо передавать внешнему AI.

## Что считается чувствительным

- API-ключи;
- токены;
- credentials;
- приватные prompts;
- `.env`;
- рабочая память проектов;
- пользовательские данные;
- внутренние конфигурации;
- секреты из логов и исключений.

## Перед передачей AI

Контекст проходит:

```text
Selection
   ↓
Reference Check
   ↓
Secret Detection
   ↓
Sensitivity Check
   ↓
Budgeting
   ↓
Handoff
```

## Локальный и облачный контекст

Для локальных и облачных исполнителей могут применяться разные требования к допустимому контексту.

## Публичный Showcase

Этот Showcase публикует только:

- архитектуру высокого уровня;
- инженерные принципы;
- обезличенные workflow;
- общие результаты тестирования;
- безопасные технические схемы.

Не публикуются:

- production credentials;
- реальные project memory files;
- приватные prompts;
- API keys;
- рабочие runtime databases.
